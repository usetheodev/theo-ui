## New structural gates

`scripts/validate-quality-gates.ts` now enforces:

1. `validateGovernanceFiles` — fails if `LICENSE`, `CHANGELOG.md`, or `README.md` is missing, or if CHANGELOG.md lacks `## [Unreleased]`.
2. `validateReadmeDrift` — fails if README mentions a `Component` in backticks that is not exported from `src/index.ts`.
3. `validateDocsTypography` — fails if `docs/design-system.md` is missing `Geist` reference, or mentions Boska/Switzer/JetBrains Mono outside a `## Histórico` section.
4. `validateCompositeBarrel` — fails if a composite imports a primitive via raw `*.js` file instead of `index.js` barrel.
