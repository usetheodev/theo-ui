# Registry

`@theokit/ui` distributes two ways: install the whole package, or copy individual
components via the shadcn-compatible registry. **The copy-paste path is first-class, not a
side feature.**

| Concept | What it answers |
| --- | --- |
| [shadcn registry](/registry/shadcn-registry.md) | How the registry is built, hosted, and consumed. |
| [Component census](/registry/component-census.md) | The generated list of exported primitives and composites. |

The gate that keeps registry items installable is
[`/quality-gates/registry-gate.md`](/quality-gates/registry-gate.md).
